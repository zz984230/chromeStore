## 降级路径与根因记录（如实标注）

1. **CDP 合成键盘不触发扩展命令**：tabbit `page.keyboard` 派发的 Alt 组合键两次实验均未触发 `pace-up`——改由用户手动按键 + tabbit DOM 监听读取档位。
2. **suggested_key 对"已安装扩展新增的 commands"不生效**：M1 首装时无 commands，M2 重载新增后键位显示「未设置」（Chrome 仅在首次安装时应用 suggested_key）。**商店新装用户不受影响**。开发环境解法：`chrome://extensions/shortcuts` 手动绑定。此现象为开发流程特有，不构成发布缺陷。
3. **tabbit 任务标签跨调用重置**：user-delay 后新提交获得新隐式页，需在单程序窗口内完成「监听 + 用户操作」配合（后台长窗监听模式），或重新导航。

验收 #2、#3、#7 通过；M2 关账。回归基线：38/38 单测，build exit 0。
