## 用户上报缺陷修复：片尾收尾重复 seek（2026-09-18）

**缺陷**：用户在 bilibili 上报——跳过开启且片尾值较大时，视频一到结尾，每次 timeupdate 都重复 `currentTime = duration`，连续 seek 把播放器锁死（画面冻结、播放键无响应）；保密观上同机制把 AliPlayer 推入错误/刷新面板。与上文「发现与记录」#1 的 backlog 项一致，本次落地修复。

**根因**：`outroAction` 无 at-end/ended 守卫——`remaining < outroSkip` 在 `remaining ≈ 0` 时恒真，收尾动作永远重复触发。

**修复**：`src/content/main.js` 的 `onTimeUpdate` 在 duration 守卫后、outroAction 计算前新增一行守卫：`video.ended || d - video.currentTime <= 0.3` 则直接返回——已结束/已贴尾的视频不再重复 seek。单测新增「片尾收尾不重复触发：已贴尾/已结束不再 seek」钉住：首次 97→100 收尾一次，其后贴尾与 ended 均 0 seek。

**病态配置告警仍成立（如实）**：片尾 ≳ 视频时长时，按语义任意位置都落在片尾区间，起播即收尾（AliPlayer 错误态）——该行为由语义决定，本次守卫不改变它；常规值（≤60s）下，播放到结尾→重播/续播的完整链路在到达最后 0.3s 窗口前不受影响。用户测试后应把片尾调回小值。

**回归**：`npm test` 73/73（72 + 1）；`npm run build` clean。
