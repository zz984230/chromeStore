# Octopus

Octopus(章鱼)是工具的瑞士军刀:一个浏览器扩展容纳多个独立工具,后续所有工具开发都在此进行。前身是 NightVeil(暗色)与视频倍速助手(档位)两个项目。本文件只定义伞形术语;各工具的专属词汇表见各自工具目录下的 CONTEXT.md。

## Language

**工具(Tool)**:
用户可独立发现、独立启停、独立配置的功能单元;拥有自己的存储命名空间、页面行为与弹窗入口。工具之间零耦合,互不引用对方代码。
_Avoid_: 模块、功能、feature、插件(那是扩展本身)

**共享层(Shared)**:
所有工具共同使用的基础设施(storage 封装、消息总线、文案单源、图标、DOM 工具);只放与具体工具业务无关的代码。
_Avoid_: 公共库、common、utils 大杂烩

**壳(Shell)**:
octopus 自身的部分:唯一的 background/popup/options/manifest、工具注册表、消息路由、存储封装、文案聚合。工具代码不得反向触壳。
_Avoid_: 宿主、框架、main

**工具契约(Tool Contract)**:
工具接入壳的声明式接口:id、显示信息、面板模块、设置 schema、content 注入片段、SW 生命周期钩子、快捷键、manifest 增量。按「页面注入+设置+面板+快捷键」的已验证形状设计,不适用的槽位留空。
_Avoid_: 插件接口、API、协议

**注册表(Registry)**:
构建期枚举全部工具、装配 manifest 与壳 UI 的名录;新增工具 = 加目录 + 一行注册。
_Avoid_: 插件列表、tool list

### 工具名册

**夜幕(veil)**:
第一个工具:把网页整体转为暗色外观。前身 NightVeil(夜纱),popup tab 名回归「夜幕」(2026-10-18 用户裁定),代码命名空间沿用 nv-。
_Avoid_: 夜纱、NightVeil(仅历史文档可用)、暗色模式(旧称)

**倍速(pace)**:
第二个工具:在任意网页调节 HTML5 视频播放档位。前身「视频倍速助手」,代码命名空间沿用 vpa.。
_Avoid_: 视频倍速(旧全名)、视频倍速助手

**当前工具(Active Tool)**:
popup 正在展示面板的工具。选择持久化,重开回到上次工具;首次安装默认夜幕。
_Avoid_: 活动标签、选中工具

**换盘(Plate swap)**:
工具栏图标按当前标签页的暗色实效在深盘/浅盘间切换的机制;章鱼图形不变,只换配色,中性盘为默认。
_Avoid_: 图标切换、icon state、真话图标(口语可用,不入正式文档)

**工具字形(Tool glyph)**:
popup 工具 tab 上代表工具的小图形(月牙、»),继承自旧项目的图标资产。
_Avoid_: 工具 logo、tab icon

**双层设置(Two-layer settings)**:
工具设置的分层惯例:popup 面板放快捷子集,设置页放完整集;两处同源一份存储,不是两份数据。
_Avoid_: 设置重复、镜像设置

**通用(General)**:
设置页中存放壳级偏好(关于、版本)的分区,不属于任何工具。
_Avoid_: 系统、全局(易与暗色工具的 Global State 混淆)
