# 对比(diff)

章鱼的第三只工具、第一只工作台型:在工作页里做行级文本对比与合并。功能蓝本是 DiffSuite(功能等价复刻,视觉与文案自有);格式归一化(JSON/YAML/TOML)为后续里程碑。本文件只放对比工具的专属词汇。

## Language

**归一化器(Normalizer)**:
对比管线的一段:text→text 的预处理(如 JSON 解析后按规范形重排),位于输入与行级 diff 之间;恒等归一化器即纯文本对比。新增格式支持 = 新增一个归一化器,diff 引擎不动。
_Avoid_: 解析器(它不止 parse,还负责规范形输出)、格式化器(听不出「为对比服务」的职责)

**差异块(Chunk)**:
行级 diff 输出中,同一位置上交替出现的删除行(-)与新增行(+)构成的最大连续段。合并的最小决策单元:每块一个箭头,采纳即整块——本侧的行搬到对面(替换或插入),随后立即重算 diff,两边一致的块从结果消失。输入框是唯一事实源,结果视图永远派生。
_Avoid_: hunk(英文口语可用,中文文档用差异块)、差异组、变更集

**降级(Degraded diff)**:
输入差异过大(编辑距离超限)时的诚实呈现模式:公共前后缀照常裁剪,中间整块呈现为一个大差异块,页面明示已降级。与「拒绝」相对——拒绝只说不行,降级交付可用的半成品。
_Avoid_: 失败、fallback(口语可用,中文文档用降级)
