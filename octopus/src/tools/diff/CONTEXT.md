# 对比(diff)

章鱼的第三只工具、第一只工作台型:在工作页里做行级文本对比与合并。功能蓝本是 DiffSuite(功能与渲染结构等价复刻,色值按暗盘重调,文案自有);格式归一化(JSON/YAML/TOML)自 M4 起入驻。本文件只放对比工具的专属词汇。

## Language

**归一化器(Normalizer)**:
对比管线的一段:text→text 的预处理(如 JSON 解析后按规范形重排),位于输入与行级 diff 之间;恒等归一化器即纯文本对比。新增格式支持 = 新增一个归一化器,diff 引擎不动。
_Avoid_: 解析器(它不止 parse,还负责规范形输出)、格式化器(听不出「为对比服务」的职责)

**规范形(Canonical form)**:
归一化器的输出形态,三原则:值等价的输入得到同一文本(同值不同写法——转义、引号风格、flow 与块——收敛为单一写法);幂等(对规范形再归一化,输出不变);各格式各自规范形,不跨格式统一。合并把结果搬回输入框,规范形自此长住输入框——像跑过一遍 formatter。
_Avoid_: 标准形(听不出「为对比服务」的目的)、格式化输出(目的是等价收敛,不是好看)

**差异块(Chunk)**:
行级 diff 输出中,同一位置上交替出现的删除行(-)与新增行(+)构成的最大连续段。合并的最小决策单元:每块一个箭头,采纳即整块——本侧的行搬到对面(替换或插入),随后立即重算 diff,两边一致的块从结果消失。输入框是唯一事实源,结果视图永远派生。
_Avoid_: hunk(英文口语可用,中文文档用差异块)、差异组、变更集

**降级(Degraded diff)**:
输入差异过大(编辑距离超限)时的诚实呈现模式:公共前后缀照常裁剪,中间整块呈现为一个大差异块,页面明示已降级。与「拒绝」相对——拒绝只说不行,降级交付可用的半成品。字符级高亮另有静默降级:超限即回整行铺色,页面不明示——字符块是增强层,缺席不损诚实。
_Avoid_: 失败、fallback(口语可用,中文文档用降级)

**字符级高亮(Intra-line highlight)**:
差异块内配对行的行内差异标记:行底色之上再叠一层更深的字符块,标出真正变动的字符。行级 diff 回答「哪些行变了」,它回答「行内哪些字变了」。
_Avoid_: 词级高亮(粒度是字符不是词)、行内 diff(口语可用,中文文档用字符级高亮)

**配对行(Paired lines)**:
差异块内按下标配对的删除行与新增行(第 i 条删配第 i 条增);字符级高亮只在配对行上计算,落单行(块内两侧行数不等时多出的行)整行铺色。只服务呈现,不影响合并——合并仍以差异块为单位。
_Avoid_: 对应行、匹配行(听不出是按位置的呈现约定)

**中缝(Merge gutter)**:
左右结果栏之间的窄缝:每个差异块一对箭头,⇜ 取右栏(推到左)、⇝ 取左栏(推到右)。是「差异块=合并最小决策单元」在视图上的锚点。
_Avoid_: 中栏、工具条(它不承载工具,只承载块级合并动作)
