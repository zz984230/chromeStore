## 工具级验收

### 暗色模式（veil）

原文照搬自 `dark-mode/nightveil/自主迭代.md`「验收标准（Definition of Done）」：

每次改动后，以下条目必须全部通过才算完成：

**通用条目（每轮必查）**
1. [ ] `extension/` 在 chrome://extensions 无报错加载（无红色错误、无黄色警告）
2. [ ] 打开验收页后 content script 正常注入（console 无未捕获异常）
3. [ ] service worker console 无新报错
4. [ ] `tests/` 中已固化的回归测试全部通过

**里程碑条目（当前：M1，进入新里程碑时整体替换本节，旧条目转入回归测试）**
5. [ ] 点击工具栏图标，plain.html 在 Light/Dark 间切换，图标与标题随状态变化
6. [ ] 选择某个 Classic Theme 后刷新页面主题仍生效（持久化）；换选另一主题立即替换
7. [ ] Exclusion List 加入当前域名后该站不再生效；Inclusion Mode 下仅列表内域名生效
8. [ ] options.html 各分区可展开、修改即自动保存、Reset 恢复出厂设置

### 视频倍速（pace）

原文照搬自 `video-acc/自主迭代.md`「验收标准（Definition of Done）」：

每次改动后，以下条目必须全部通过才算完成：
1. [ ] 扩展能在 `chrome://extensions` 无报错加载（无红色错误、无黄色警告）
2. [ ] 打开保密观测试视频页后，content script 正常注入（console 无未捕获异常），popup 能读到当前视频实际档位
3. [ ] popup 滑块/预设调档 → 视频实际播放档位改变，浮标短暂显示（保持模式带 🔒）
4. [ ] 保持模式开启时刷新页面/切换集数，档位自动恢复；保持关闭时不干预新视频
5. [ ] 片头/片尾跳过按规则生效（开始播放时越过片头；临近片尾时循环视频暂停、普通视频跳到结尾）
6. [ ] 自动续播：视频自然结束后能找到并点击"下一节"类按钮；站点自身已连播时不干预
7. [ ] service worker console 无新报错

## 平台级验收（octopus M0 新增）

壳层条目，与工具级验收并行生效：

1. [ ] manifest 装配正确性：`extension/manifest.json` 全量由 `assembleManifest(tools, { version })` 构建期装配——壳基座（名称/描述/版本单源壳文案与 package.json）+ 各工具契约增量（权限并集去重、content_scripts 逐字段保真、commands 合并、web_accessible_resources 汇总）；装配钉子测试在场且全绿（`tests/shell/manifest.test.mjs`、`tests/shell/build.test.mjs`）
2. [ ] 注册表完整性：`src/tools/registry.js` 的 `TOOLS` 覆盖全部在册工具、id 唯一、契约字段（permissions / optionalPermissions / hostPermissions / contentScripts / webAccessibleResources / commands）齐全（`tests/shell/registry.test.mjs`）
3. [ ] 壳存储隔离：壳只读写 `oct.shell` 单键，不与工具存储键（`nightveil.settings`、`vpa.settings`）互扰；非法工具 id 拒绝写入（`tests/shell/store.test.mjs`）
4. [ ] 零工具互引：grep 断言三连零命中（在 `octopus/` 内执行）——

   ```bash
   grep -rn "tools/veil" src/tools/pace | wc -l && grep -rn "tools/pace" src/tools/veil | wc -l && grep -rn "tools/veil/\|tools/pace/" src/shell | grep -v "src/shell/popup.js\|src/shell/background.js\|src/shell/options.js" | wc -l
   ```

   预期 `0`、`0`、`0`：前两条 = 工具互引为零；第三条 = 壳除 popup/background/options 三个装配入口外不触工具内部（2026-10-04 M0 关账实测 0/0/0）。
