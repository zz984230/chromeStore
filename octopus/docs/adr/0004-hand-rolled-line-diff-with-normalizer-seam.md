# 自研行级 diff 引擎与归一化缝

对比工具(diff)的文本对比引擎自研:Myers O(ND) 行级算法 + 公共前后缀裁剪,不引 jsdiff/diff-match-patch 等任何运行时依赖。格式支持(JSON/YAML/TOML)走「归一化器」缝——text→text 的预处理(parse 后按规范形重排)插在输入与行级 diff 之间,v1 只装恒等归一化器;后续每支持一种格式 = 新增一个归一化器,引擎一行不动。

引库的论据不成立:jsdiff 们的真本事在词级/字符级与多粒度,而本工具裁定只做行级;且它们对 TOML/YAML 一无所知——格式支持无论如何都要 vendor 解析器,与引不引 diff 库是两笔账。自研的代价由护栏兜底:每侧 20,000 行或 2MB 硬顶拒绝,中间段编辑距离超限(初值 1,000)降级为「前后缀照裁+整块呈现+页面明示」,数字是单点常量,真机校准。章鱼保持零运行时依赖,LICENSE/打包链/隐私叙事零摩擦。
