# 归一化缝装真归一化器:契约升级与双道护栏

M4 把 JSON/YAML/TOML 装进 0004 留下的归一化缝。缝的契约从 text→text 一元函数升级为结果对象 `{ ok: true, text } | { ok: false, reason }`,reason 结构化(kind: 语法错/子集外,行列,细节),compare 按哪一侧调用失败归属栏名;单边失败整体拒算——不降级、不出半成品,banner 复用护栏拒绝家族,文案 strings.js 单源,shared 层零文案。规范形三裁定:值等价⇒文本等价(同值不同写法收敛为同一文本——JSON 的 1e2≡100、字符串转义写法≡明文,TOML 的 0xFF≡255、单双引号风格,YAML 的 flow≡块;否则字符级高亮会盯着无意义的写法差异报差异);幂等(合并把结果搬回输入框,规范形自此长住其中,非幂等即震荡);各格式各自规范形(键码点排序、数组保序、每键一行 2 空格、文末一换行),不做跨格式统一——TOML 日期/YAML 特有类型不降维成字符串,类型零损失。

护栏从一道变两道:原文过 checkSide → 归一化 → 产物再过同一 checkSide。压缩 JSON 展开 pretty 可能顶穿 2MB/两万行,超限即拒绝,banner 区分「归一化后超限」并按栏归属——原文超限改输入可救,展开超限只能放弃 pretty 对比,对用户是不同的下一步。范围裁定:JSON 用内置 JSON.parse(JS number 语义,>2^53 精度损失为已知限制,接受);TOML 收 1.0 全谱;YAML 收常用配置子集——块映射/序列、三式标量、块标量 `|` `>`、flow、1.2 核心 schema 类型(1.1 的 no/On 布尔坑不收),锚点/别名/合并键/多文档/标签/复杂键合法但子集外,拒算并指明——宁可说不行,不静默错。新增格式仍是注册表添一员,引擎一行不动。
