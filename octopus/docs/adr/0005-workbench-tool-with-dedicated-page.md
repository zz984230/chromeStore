# 工作台型工具与独立工作页

对比工具(diff)是章鱼第一只**工作台型工具**——在扩展自己的页面里完成整段工作,不触碰外部网页;与夜幕/倍速的**注入型**(把行为注入用户正在浏览的网页)构成形态分野,记入伞形 CONTEXT.md 的「工具形态」。其载体是 `public/` 下的独立工作页(`diff.html`),由壳经 `chrome.tabs.create` 在新标签页打开;popup 的工具 tab 退化为纯启动器(一键直达)。

落选的两条路:塞进 options 页当翼,会打穿「双层设置」惯例并撑爆设置页语义;只做 popup 面板,360px 容不下双栏+行号+合并箭头的工作台。扩展内部页面开标签页不需要 `web_accessible_resources`,manifest 零增量。本 ADR 为后续工作台型工具(记事本、剪贴板历史之类)立先例:工具契约的「工作页」槽位由此而来,注入型工具该槽位留空。
