# 将 NightVeil 与视频倍速助手合并为 Octopus

两个扩展在 2026-10 均未上架、零存量用户,合并成本处于历史最低点;产品定位从单一功能扩展转向「工具的瑞士军刀」——一个扩展容纳多个工具,后续所有工具开发都在此进行。决定:在 chromeStore monorepo 根新建 `octopus/` 平级目录,两个旧项目冻结归档(不删,保审计链与验证证据);用户可见文案去品牌(工具名改「暗色模式」「视频倍速」),代码标识符(`nv-`/`vpa.` 前缀、类名、函数名)原封不动——它们是工具边界的物理载体,重命名是纯风险零收益的苦役。

## Considered Options

- 就地演进(改造 nightveil 为 octopus):历史提交与目录错位,弃。
- 独立新仓库:破坏 monorepo 单条 git 历史与验证证据链,弃。
