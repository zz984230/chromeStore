# 通用主题用参数化调色板引擎实现，而非逐主题手写 CSS

原版 40 个通用主题各自是独立 CSS 文件（20~269 行/个）。逐文件模仿其选择器与色值等于抄资产，违反防拷贝约束；而为 40 个主题各写一份等价 CSS 又是数千行的重复劳动。

决定：自己设计两套基础样式表（Overlay 覆盖式 / Invert 反色式），40 个 Classic Theme = 40 组 Palette 参数（26 组 Overlay + 14 组 Invert，族类划分与原版语义对齐）。引擎在构建期或运行期把参数注入基础样式生成最终 CSS。

## Consequences

- 新增主题只需加一组 Palette 参数，维护成本从"每主题一个文件"降为"每主题一行参数"。
- 主题视觉效果是本项目的原创设计，**刻意不与原版同色**——这是保真度边界（ADR-0003）的有意结果，不是缺陷；"对等"的标准是风格类别与数量，不是色值。
