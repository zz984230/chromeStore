**Goal:** 按 grilling 七项裁决与已认可设计稿（designs/2026-09-19-popup-mockup.html，afbe972）交付 popup：点击工具栏图标弹 360px 快捷面板（站点行/全局开关/三席/色温浓度），直切退役，图标真话化（跟随当前标签页生效态），perSiteToggle 删除。

## Global Constraints

- 设计权威：designs/2026-09-19-popup-mockup.html——tokens 与组件类以稿为准（.dusk-mini/.dusk-switch 92px 版/.site-row/.site-pill/.seats-mini/.grp/.foot）；文案单源 strings.js（新增 popup 键，值照稿）。
- 行为边界（grilling Q7）：设置模式**仅删** `perSiteToggle`（DEFAULT_SETTINGS + 选项页杂项行 + toolbarClickPatch 链 + 相关单测）；**零新增设置键**（popup 读写既有 state/themeId/colorTemperature.enabled/opacity/exclusionList/inclusionList/inclusionMode）。

- 站点行语义（Q3）：统一按站点开关——排除模式：on ⟺ hostname ∉ exclusionList（点击切换加/移除）；包含模式：on ⟺ hostname ∈ inclusionList（点击切换加/移除）。hostname 规整沿用 `hostnameFromUrl`/`normalizeHostname`。
- 图标真话化（Q4）：per-tab 图标 = 全局 dark 且该站点生效（按上式）→ 暗图标；否则亮图标。title 同步（用既有 stateTitle* 键）。tabs.onUpdated + tabs.onActivated + storage 变更全量刷新。
- 测试：npm test 全绿后提交；测试期望变更仅限 perSiteToggle 删除的 lockstep（actions 单测相应简化）与新增。
- 构建：npm run build 四入口零错误；源在 public/ 与 src/，extension/ 为产物。
- 提交前缀 feat(m3+2)/fix(m3+2)/test(m3+2)，结尾 Co-Authored-By 行。
- 禁止顺手改良。

### Task 3: popup 渲染与交互

**Files:**
- Create: `src/popup/main.js`
- Modify: `src/shared/optionsM3.js`（seatRadioValue 从 options/main.js 迁入并导出）
- Modify: `src/options/main.js`（改用共享导入）

**Interfaces:**
- Consumes: settings.js（loadSettings/saveSettings/subscribeSettings）、actions.js（hostnameFromUrl）、scope.js（normalizeHostname/hostnameInList）、palettes.js（PALETTES）、optionsM3.js（SEAT_CARDS/seatRadioValue）。
- Produces: popup 完整交互面——
  ```js
  // shared/optionsM3.js 新导出
  export function seatRadioValue(themeId); // 'adaptive'|'custom' 原样，其余 → PALETTES[0].id（实现迁自 options/main.js）
  ```
  popup 行为钉死项：
  1. 启动：`chrome.tabs.query({active:true, currentWindow:true})` 取 tab.url → hostname；`loadSettings()` 渲染。无 tab URL（chrome:// 等内部页）→ 站点行显示域名占位 `—` 且禁用（internal 页不可作用域控制），其余组照常。
  2. 大开关 ↔ settings.state（change → save({state})）；文案随 state 切换（duskTitleOn/Off + popupGlobalSubOn/Off）。
  3. 站点行：按 Q3 语义渲染当前态（副文案 + 胶囊文字四态：排除模式生效/已排除、包含模式已加入/未加入）；点击 → save 对应列表增/移（读-改-写经 saveSettings 单键 patch，hostname 用 hostnameFromUrl 规整）。
  4. 三席：三个 radio（name themeId，value= adaptive/PALETTES[0].id/custom）+ seatRadioValue 派生勾选；change → save({themeId})。经典/自定义席位在 popup 不展开面板（无色板/编辑器——全参数在选项页；席位卡片仅切换）。
  5. 色温：开关 ↔ colorTemperature.enabled；浓度滑杆 ↔ colorTemperature.opacity（input 实时 save + --fill + 圆点 rgb(255 227 199 / v%)）；开关关 → 滑杆行 dimmed。
  6. 底部「全部设置」→ `chrome.runtime.openOptionsPage()`；品牌行静态文案。
  7. subscribeSettings 重派全部控件（popup 生命周期短，防外部变更即防竞态）。
